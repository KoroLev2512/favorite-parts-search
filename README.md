# Подбор запчастей (тестовое задание Favorit Parts)

Клиентское приложение на React + Redux для поиска автозапчастей и аналогов через web-сервис «Проценка».

## Как работает

1. Пользователь вводит артикул, приложение запрашивает список производителей с этим номером.
2. После выбора производителя идёт второй запрос с `brand` и `analogues=on`, и выводится таблица: название, производитель, артикул, цена и остаток.

Цена берётся со складов (минимальная среди складов, где товар есть), а не из общего поля `price`: в документации это поле помечено «не использовать».

Обрабатываются загрузка, пустой ответ (деталь не найдена), ошибки API (`{"error": ...}`, например неверный ключ) и сбой сети. Для ошибок есть кнопка «Повторить». Ответ на устаревший запрос (если пользователь успел начать новый поиск) игнорируется.

## Запуск

```bash
npm install
cp .env.example .env   # при необходимости подставьте свой ключ
npm run dev
```

API не отдаёт CORS-заголовки для сторонних доменов, поэтому запросы идут через прокси: в разработке через `server.proxy` в Vite, на Vercel через `vercel.json`.

## Стек

React 18, Redux Toolkit (createSlice, createAsyncThunk), react-redux, Bootstrap 5, Vite. Без TypeScript, как в задании.
